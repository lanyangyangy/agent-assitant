# Agent 控制台视觉概念说明

前端 A 版视觉概念已在 2026-08-12 生成，用于后续实现对照：

- 三栏工作台：左侧会话，中间聊天，右侧工具事件与工具目录。
- 浅色冷静工程台风格：`#f7f8fb` 背景、白色面板、蓝灰文字、细边框。
- 状态色：蓝色表示进行中，黄色表示工具调用，绿色表示成功，红色表示错误。
- 关键中文 UI 文案：`Agent 控制台`、`后端正常`、`新建会话`、`聊天输入`、`发送`、`工具事件`、`调用工具：calculator`、`工具结果：calculator`、`437`、`工具目录`。

后续浏览器验收以此说明和已确认的视觉伴随 A 版线框为准。
